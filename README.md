# AI Act на русском

Неофициальный перевод Регламента (ЕС) 2024/1689 об искусственном интеллекте (AI Act) на русский язык — по одной статье в неделю, с пояснениями простыми словами и схемами.

Официальных переводов AI Act на русский нет: ЕС публикует законы только на своих 24 официальных языках. Этот проект закрывает пробел для русскоязычных специалистов, предпринимателей и студентов в ЕС и за его пределами.
